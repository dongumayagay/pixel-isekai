
## Token discipline
- Be token-efficient. Short replies, no narration, no restating. Code via heredocs, not long Read dumps.
- One render per iteration, small crops at 2-3x. Never dump big sheets to look at a detail.
- Never re-read files already in context. Never print whole files. Grep for the lines you need.
- Batch independent tool calls. Diagnose with numbers before rendering again.
- Decide, don't ask. Report in <=8 lines unless asked for detail.
