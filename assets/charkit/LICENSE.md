# Liberated Pixel Cup character kit

The sheets in this directory are the walk and idle animations of parts from the Universal LPC
Spritesheet Character Generator (https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator),
stored as palette-indexed PNGs (index 1-6 = the material's base colour ramp) so the game can recolour
them. Authors and licences per sheet directory are in CREDITS.csv (CC-BY-SA 3.0, GPL 3.0 and/or
OGA-BY 3.0). Derived character art in this game is shared under CC-BY-SA 3.0.
